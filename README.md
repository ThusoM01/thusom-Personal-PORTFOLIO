# Thusom's Personal Portfolio

A modern, responsive personal portfolio website showcasing projects and skills.

## 🚀 Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional design with smooth animations
- **Dark Theme**: Easy on the eyes with a modern dark color scheme
- **Sticky Navigation**: Easy navigation with a persistent header
- **Project Showcase**: Display your best work with project cards
- **Skills Section**: Highlight your technical skills
- **Contact Section**: Easy way for visitors to reach out

## 🛠️ Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ThusoM01/thusom-Personal-PORTFOLIO.git
   cd thusom-Personal-PORTFOLIO
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

4. Open your browser and visit `http://localhost:8000`

## 📝 Customization

### Update Personal Information

- Edit the hero section in `index.html` with your name and title
- Update the about section with your bio
- Replace project placeholders with your actual projects
- Update contact links with your real email and social media

### Modify Colors

Edit the CSS variables in `css/styles.css`:

```css
:root {
  --primary-color: #2563eb;
  --secondary-color: #1e40af;
  /* ... other variables ... */
}
```

## 🎨 Color Scheme

- **Primary**: #2563eb (Blue)
- **Secondary**: #1e40af (Dark Blue)
- **Background**: #0f172a (Very Dark Blue)
- **Text**: #f1f5f9 (Light)
- **Gray**: #cbd5e1 (Gray)

## 📱 Responsive Breakpoints

- **Desktop**: 1200px and up
- **Tablet**: 768px to 1199px
- **Mobile**: Below 768px

## 🚀 Deployment

### Deploy to Vercel

1. Push your changes to GitHub
2. Go to [Vercel](https://vercel.com)
3. Import your repository
4. Vercel will automatically deploy your site

### Deploy to GitHub Pages

1. Push your changes to the `main` branch
2. Go to your repository settings
3. Scroll to "GitHub Pages"
4. Select `main` branch as the source
